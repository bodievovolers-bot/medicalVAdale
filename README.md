# Aeron Morrondoz | Medical Virtual Assistant

Portfolio website for Aeron Dale D. Morrondoz, a Medical Virtual Assistant who supports US clinics with scheduling, insurance verification, prior authorization, claims support, and patient billing.

**Live site:** https://YOUR-SITE-NAME.vercel.app *(replace with your Vercel address after deploying)*

## What is on the site

- **About:** background in nursing and BPO customer service, and how I work with clinics.
- **Skills:** healthcare administration, billing basics, customer service, and systems.
- **From Intake to Settlement: RCM Process:** an animated, step-by-step map of one patient visit, from the first phone call to a paid bill, with plain-English explanations and a short glossary. All examples use a fictional patient.
- **Toolkit, Services, Experience, Training, Contact.**

No real patient information appears anywhere on this site.

## Run it locally

Open `index.html` in any web browser. No install or build step is needed.

## Deploy on Vercel

1. Push `index.html` to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Click **Deploy**. No settings need to be changed, because this is a static site.

To update the site later, replace `index.html` in the repository and commit. Vercel republishes automatically.

## Tech

Plain HTML, CSS, and JavaScript. No frameworks or dependencies. Fonts load from Google Fonts. The page works on desktop and phone and respects the "reduce motion" setting.
